# TA 8 BIT

Original, unmodified TrueType font by TA Font (Taweechai Aswarangsitsang).
Source: https://www.f0nt.com/release/ta-8-bit/
Downloaded 2026-09-06 from the author's distribution on f0nt.com.

The author permits free personal and commercial use and prohibits selling the font itself.
General distribution terms: https://www.f0nt.com/about/license/
Bundled here solely to render this application, not as a standalone font download product.

Thai positioning uses the font's liga substitutions: keep ligatures enabled.
The same font supplies Thai and Latin. Synthetic bold is disabled to preserve pixel contours.
