## แก้ไขและส่งออกใหม่

แก้เนื้อหาใน `pages` และรูปแบบใน `css` / `compact` ของ `build.mjs` แล้วรันจากรากโปรเจกต์:

```powershell
node artifacts/manual-v24/build.mjs
```

ใช้ Node.js, Playwright/Chromium ที่ติดตั้งในโปรเจกต์ และฟอนต์ Google Sans Regular/Bold ใน `fonts/`
ใช้ภาพเดิมจาก `public/pixel/` และโลโก้จาก `components/brand.tsx`
ไม่ต้องเปิดแอปหรือเชื่อมต่อฐานข้อมูล สคริปต์เขียนเฉพาะไฟล์ในโฟลเดอร์คู่มือนี้
`manual.html` เป็นผลลัพธ์ที่แก้ไขได้โดยตรง แต่การรัน build จะสร้างไฟล์นี้ใหม่จากสคริปต์
ฟอนต์ Google Sans ฝังใน HTML ทั้งสองน้ำหนัก จึงไม่ต้องติดตั้งฟอนต์หรือเชื่อมต่อเครือข่าย
ดาวน์โหลดจาก [Google Fonts](https://fonts.google.com/specimen/Google+Sans) ผ่าน CSS API ของ Google
ใบอนุญาต SIL Open Font License อยู่ใน `fonts/OFL.txt` จากโครงการ `googlefonts/googlesans`
ตรวจด้วย Chromium ว่าข้อความไทยในหัวเรื่องและเนื้อหาใช้ Google Sans จริง ไม่มีฟอนต์ระบบแทน
โลโก้ KILLER เป็นภาพ SVG เดิมของเกม
